# 🌤️ SkyTasks — Sistema de Lista de Tarefas  
### Desenvolvido por **SkyTech Solutions**

---

## 📌 Sobre o Projeto
O **SkyTasks** é um web-app responsivo criado para facilitar a gestão de tarefas do dia a dia.  
Foi desenvolvido como entrega da **N2**, seguindo os requisitos de:

- Criar um **web-app**
- Interface **responsiva**
- Aplicação funcional e intuitiva
- Código organizado em HTML, CSS e JavaScript
- Uso de tecnologias web modernas

O sistema funciona diretamente no navegador, sem necessidade de instalar nada.

---

## 🚀 Funcionalidades

✔ Adicionar tarefas  
✔ Definir data usando **calendário (Flatpickr)**  
✔ Selecionar prioridade (Baixa, Média, Alta)  
✔ Filtrar tarefas (Todas, Pendentes, Concluídas)  
✔ Editar tarefa clicando duas vezes  
✔ Marcar como concluída  
✔ Remover tarefa  
✔ Limpar tarefas concluídas  
✔ Armazenamento local com **LocalStorage**  
✔ Design moderno e totalmente **responsivo**

---

## 🧪 Como usar

1. Abra o link do projeto:
   👉 https://leoskyy.github.io/skytasks/

2. Adicione uma tarefa digitando o texto  
3. Escolha uma data  
4. Defina a prioridade  
5. Clique em **Adicionar**

A tarefa aparecerá automaticamente na lista.

---

## 📱 Responsividade
O SkyTasks funciona perfeitamente em:

- Smartphones 📱  
- Tablets 📲  
- Notebooks 💻  
- Monitores grandes 🖥️  

A interface se adapta automaticamente ao tamanho da tela.
